# 会话花费与余额 · Session Cost

[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 插件：在输入框下方查看当前会话的费用估算，点开面板查看用量、账号余额和近期累计。

**版本 0.2.0** · **AGPL-3.0-or-later** · 已在 **macOS / DSH Desktop 0.2.0-rc.2** 验证。

这是独立插件，可以单独安装；[会话标题命名](https://github.com/ygnstudio/dsh-plugin-title-oil) 是另一个可选插件。

## 能做什么

- **会话费用**：根据模型返回的 token 用量与价格表估算，区分输入、输出和缓存用量；未配置价格的模型会标注未计价。
- **费用面板**：点击输入框下方的费用条，查看本会话明细、今日和近 7 天累计；按 Esc 或点击外部关闭。
- **余额与套餐**：管理多个账号，按供应商绑定当前会话，设置后台查询、面板监控和低余额提醒。
- **失败状态可见**：鉴权失败、超时和旧缓存有明确提示；保存失败保留草稿，避免多窗口覆盖配置。

费用数字是估算，供应商账单为准。自动命名等辅助模型调用不在主会话用量里；第三方账号的余额查询也不代表其模型已配置会话计价。

## 安装

### 桌面版：从插件管理器安装（推荐）

1. 打开 DSH 左侧的 **插件 → 添加插件**。
2. 在安装目标中粘贴：

   ```text
   github:ygnstudio/dsh-plugin-session-cost#v0.2.0
   ```

3. 点击安装，完成后选择 **立即启用**。
4. 若管理器提示需要重启，完全退出并重新打开 DSH。插件详情显示「运行中」后，打开任意会话检查费用条。

仓库包含可直接加载的 JavaScript，**不需要构建，也没有安装脚本**。当前通过 GitHub 分发，尚未发布到 npm；不要只输入裸包名。无需手动修改 profile 的 `package.json` 或 bundles。

### 使用 `dsh web` 的用户

只对独立的 `web` profile 使用以下命令；桌面版优先使用上面的插件管理器：

```sh
dsh plugin --profile web add github:ygnstudio/dsh-plugin-session-cost#v0.2.0
```

安装后重启已有的 `dsh web` 进程并刷新页面。不同 profile 独立安装；这里的 CLI 语法已对照官方实现，Web 版没有完成与桌面版同等的运行验证。

### 从本地源码安装

```sh
git clone --branch v0.2.0 https://github.com/ygnstudio/dsh-plugin-session-cost.git
cd dsh-plugin-session-cost
pwd
```

将 `pwd` 输出的绝对目录填入 **插件 → 添加插件**。宿主提供 DSH 依赖，不需要在源码目录手动安装一套 DSH。保留该目录，因为本地目录安装可能链接到源码。

## 开始使用

1. 打开 **插件 → 会话花费与余额**，或 **设置 → 费用与账号**。
2. 在「添加账号」中选择类型并填写备注。API key 类型可手动输入，或从 DSH 已有凭据引用导入；本机登录类型从可用登录中选择。
3. 点击 **测试连接**，确认后 **添加**。
4. 在账号卡中设置预警值，选择是否开启 **后台查询** 和 **面板监控**。有多个账号时，在编辑页绑定相应的 DSH 供应商。
5. 回到会话，点击费用条查看面板。账号的 **刷新** 按钮可立即查询。

系统通知需要主动点击「开启系统通知」并在系统中允许。未授权时仍可查看界面内提醒。

### 账号支持范围

| 类型 | 凭据来源 | 显示内容与当前状态 |
| --- | --- | --- |
| DeepSeek API key | 手动输入或 DSH 凭据引用 | 充值、赠送、合计余额；已实现 |
| DeepSeek 账号 | DSH 的已登录账号服务 | 官方账号余额；已在真实桌面宿主验证 |
| Kimi For Coding | API key | 5 小时与周窗口剩余比例；实验性，未完成真实账号联调 |
| Codex | 当前用户的本机 Codex 登录 | 用量窗口剩余比例；实验性，接口可能变化 |
| WorkBuddy | macOS 本机登录，可识别 WorkDaddy 账号备份 | 积分余额；实验性，依赖客户端版本与本机凭据格式 |
| CodeBuddy | — | 预留项，尚未实现，请勿作为可用适配器使用 |

账号列表每 5 分钟刷新启用后台查询的账号，最多同时查询 2 个。主会话使用的 DSH 官方钱包另按默认 2 分钟间隔刷新。短暂网络失败可保留最近成功读数并标记状态，不能把旧读数当成实时余额。

## 计费与统计说明

- 计价采用 DeepSeek 官方价格表及插件内置回退表。启动与每天尝试更新，打开面板读取本地缓存。
- 未知模型不会套用猜测价格；自定义单价需要配置插件的 `prices`，详见 [实现与接口](docs/architecture.md)。
- 高低峰采用北京时间的普通工作日规则，暂不处理法定节假日调整。
- 今日和近 7 天累计目前只聚合 CNY。账本从插件实际观察到的增量开始记录，不保证补齐安装前的历史费用。
- 旧版中无法确认会话归属的账本记录会保留，但不计入已验证的累计。
- 账号余额变化可能包含其他应用的消费、充值或赠送，不能直接当作某个会话的账单。

## 数据与隐私

默认数据目录：`~/.dsh/plugin-data/session-cost/`；设置了 `DSH_HOME` 时使用其下的 `plugin-data/session-cost/`。

- `accounts.json`：账号设置与最近查询快照。
- `pricing.json`：价格缓存与提示配置。
- `ledger.jsonl`：会话费用增量账本。

目录使用 0700、文件使用 0600 权限。**手动填写的 API key 保存在本机文件中，未额外加密**；从 DSH 导入时优先保存凭据引用。完整 key 不返回界面。

本机登录发现会读取相关应用的账号元数据；WorkBuddy 的加密昵称可能需要启动其本机辅助进程解析。余额查询由 DSH 宿主向所选供应商发送必要凭据；插件没有自建数据收集服务。不要把数据目录、账号配置或完整日志附在公开 Issue 中。

首次升级会复制旧插件目录内的数据并保留原件。源码仓库与安装包均不包含这些运行数据。

## 更新与卸载

- **更新**：备份上面的数据目录，在插件管理器按当前宿主支持的方式更换安装版本。若宿主提示先卸载再安装，使用新版本的 GitHub tag 重新安装；数据目录会保留。
- **停用**：在插件列表关闭开关。
- **卸载**：在插件详情中选择卸载。插件不会自动删除账本和账号数据。
- **Web CLI**：`dsh plugin --profile web remove dsh-plugin-session-cost`，之后重启对应进程。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 插件已安装但费用条没出现 | 确认安装到当前 profile、插件及组件均已启用；查看详情错误，按提示完全重启 |
| 刚开始显示 0 或等待用量 | 等待模型返回 usage；未计价模型需补价格，不代表免费 |
| 余额鉴权失败 | 在相应客户端重新登录，或更新 API key 后测试连接 |
| 当前会话没有匹配账号 | 在账号编辑页检查供应商绑定，并完成一次实际会话调用 |
| 统计与平台账单不同 | 检查辅助调用、价格更新时间、币种及账本开始时间 |
| 多窗口保存冲突 | 保留需要的修改，重新加载最新配置后再保存 |

## 开发与验证

开发测试使用 Node.js 22，无需安装第三方依赖即可运行离线测试：

```sh
npm test
node verify-cost-fold.mjs
node --check index.js
node --check client.js
npm pack --dry-run --ignore-scripts
```

离线测试使用合成数据，不读取真实凭据，也不调用付费模型。`verify-cost-fold.mjs` 不带参数时只运行内置断言。真实 Host 由 DSH 提供 `@deepseek-ai/dsh-tools` 等服务；普通 Node 直接导入 Host 入口不能替代宿主验证。

更多模块、HTTP API、迁移与验证边界见 [实现与接口](docs/architecture.md)。报告问题请附 DSH 版本、操作系统、插件版本、复现步骤和脱敏错误。
